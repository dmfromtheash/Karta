# Karta

Редактор карт: большой холст и очень много объектов без тормозов. Ранняя сборка.

## Скачать и запустить

1. Откройте [страницу выпусков](https://github.com/dmfromtheash/Karta/releases/latest) и скачайте архив `Karta-…-win-x64.zip`.
2. Распакуйте архив целиком в любую папку.
3. Откройте папку `Karta` и запустите `Karta.exe`.

Устанавливать ничего не нужно. Нужна Windows 10 или 11, 64 бита.

При первом запуске Windows может показать окно «Система Windows защитила ваш компьютер» — программа новая и не подписана: нажмите «Подробнее», затем «Выполнить в любом случае». Первые 20–60 секунд программа готовит библиотеку ассетов; дальше запускается сразу.

## Что умеет эта сборка

Новый холст, библиотека из 20 549 ассетов, постановка ассетов на холст, размер и слой ассета, зум колесом мыши, перемещение по холсту, отмена и повтор. Сохранения карты в файл пока нет.
